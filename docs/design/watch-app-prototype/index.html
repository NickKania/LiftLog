Lift Log for Apple Watch PROTOTYPE — NOT FOR SHIPPING

Concept only — nothing here is implemented in the app. One question: how should starting a workout, completing a set, resting, and finishing feel on the wrist, one-handed and mid-set? Same sample workout in every direction: Push Day (Bench Press 135 lb × 8, Set 2 of 4), rest 2:00, 5 of 13 sets done, 24:18 elapsed. Finish saves completed sets only — same rule as iPhone today.

1 · Try it — tap the watch

Click Complete Set, watch the rest timer, skip or let it finish, then end the workout. Live demo uses a shortened 12-second rest so you can see the “Rest complete” haptic screen. State is shown beside the watch after every tap.

Watch inputs in this concept: tap = primary action · Digital Crown = adjust reps / weight, scroll · swipe = switch exercise page · haptic (.notification) = rest complete · side button untouched (system). No keyboard, ever.

Switch direction with the floating bar below, ← → keys, or ?variant=A|B|C. Feedback like “rest screen from C, set screen from A” is exactly what this is for.

2 · Full screen board

Every screen in the flow, in the direction you have selected. Captions note the input and what syncs to iPhone.

3 · Edge states (same in all directions)

These must not lose a set or invent one. Watch actions queue offline and reconcile by set ID when the iPhone is reachable again.
